Neo AdBlocker 隱私權政策

最後更新：2025-08-25

Neo AdBlocker 重視您的隱私。我們的設計原則是：僅為提供廣告與追蹤封鎖之必要功能而運作，不蒐集、不傳輸任何個人資料。

我們如何處理資料

  • 不蒐集個人資訊：不讀取或傳輸您的瀏覽內容、輸入的文字、帳號資訊或歷史紀錄。
  • 僅本地儲存：白名單與自訂規則僅儲存在瀏覽器的 chrome.storage（本機或同步），不會上傳至任何伺服器。
  • 網路封鎖：使用 Chrome 的 Declarative Net Request（MV3）在本地比對規則封鎖廣告與追蹤請求。
  • 不與第三方分享：我們不出售、交換或分享任何使用者資料。

權限使用說明

  • declarativeNetRequest：在網路層封鎖廣告與追蹤。
  • declarativeNetRequestFeedback：僅用於除錯顯示命中規則。
  • tabs：讀取目前分頁的網域，以支援站點白名單切換。
  • storage：儲存白名單與自訂規則。
  • scripting：可選的外觀過濾（只注入 CSS 隱藏常見廣告容器，不執行遠端程式碼）。

網站存取權限（Host Permissions）

僅用於兩項功能：

  1. 外觀過濾（可選）：在頁面載入時注入少量 CSS 隱藏 ins.adsbygoogle、#google_ads_iframe 等常見廣告節點。
    不讀取或上傳頁面內容與表單資料。
  2. 站點白名單：當使用者加入白名單後，在該站停用外觀過濾並以 allowAllRequests 放行請求。
